## สิ่งที่เห็น

- **ความต่างมาจาก keywords ทั้งหมด** เมื่อใช้โค้ด branch กับ keywords ของ `main` ผลเท่ากับ `main` ทุกข้อ การแก้ขั้นขยายกราฟทุกรอบจึงไม่มีผลต่อตัววัดนี้ในคำถามกลุ่มนี้
- **มาตราที่ควรได้มาจากการค้นตัวบทเกือบทั้งหมด** ไม่มีข้อใดได้มาตราในแนวคำตอบจากการเดินกราฟ คำถามกลุ่มนี้ถามมาตราเดียวตรง ๆ จึงไม่ต้องอาศัยความสัมพันธ์ระหว่างมาตรา
- **ข้อที่เสีย (O2)** prompt ของ branch ตีความ "ส่งข้อมูลไปยังผู้ให้บริการอีกราย" เป็นการเปิดเผยและโอนข้อมูล ไม่มีคำเรื่องสิทธิขอรับหรือขอให้ส่งข้อมูล
- **ข้อที่ได้ (O12)** prompt ของ `main` ให้ keywords ระดับล่างเป็นเลขมาตรา ๒๕–๓๒ ทั้ง 8 คำ ผลค้นตัวบทจึงเป็นมาตราโทษ ส่วน prompt ของ branch จำกัดเลขมาตราไว้
- **เงื่อนไขเรื่องโทษไม่ติดผิด** ทั้ง 16 ข้อไม่มีข้อใดถูกจัดเป็นคำถามเรื่องโทษ
- **context ยาวขึ้น 20%** ผลเดินกราฟของ `main` เป็นโหนดหมวด 84 จาก 240 บรรทัด ซึ่งคำอธิบายสั้น ส่วนของ branch เป็นโหนดมาตรา 125 จาก 240 บรรทัด และแต่ละบรรทัดมีโหนดต้นทางกับทิศของเส้นเพิ่ม

## ข้อจำกัด

- 17 มาตราเป็นจำนวนน้อย ความต่าง 2 มาตราสรุปไม่ได้ว่า branch ดีกว่า
- ตัววัดนับว่ามาตราอยู่ใน context หรือไม่ ไม่ได้วัดว่าเนื้อหาที่ยาวขึ้น 20% ช่วยหรือรบกวน agent
- LLM สกัด keywords ที่ temperature 0 แต่ผลอาจต่างกันได้ระหว่างการเรียกแต่ละครั้ง รอบนี้เรียกข้อละครั้งเดียว
- ผู้เขียนคำถามและแนวคำตอบคือผู้ที่แก้โค้ด
