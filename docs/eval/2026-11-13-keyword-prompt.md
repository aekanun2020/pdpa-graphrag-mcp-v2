# ผลทดสอบรอบ 5 — แก้ prompt สกัด keywords (13 พ.ย. 2569)

ต่อจาก [รอบ 4](2026-11-13-pdpc-answers.md) ข้อมูลดิบอยู่ที่ [2026-11-13-keyword-prompt-results.json](2026-11-13-keyword-prompt-results.json)

## สิ่งที่แก้

`KEYWORD_PROMPT` ใน `lightrag/retrieval.py` เพิ่มกติกา 4 ข้อและตัวอย่าง 1 ข้อ:

1. ใช้ถ้อยคำแบบตัวบท ไม่ใช่คำพูดของผู้ถาม
2. คิดก่อนเสมอว่ากฎหมาย "ใช้บังคับ" กับผู้กระทำหรือไม่ ถ้าเป็นบุคคลที่ทำเพื่อตัวเอง สื่อมวลชน ศาล ฯลฯ ให้ใส่คำเรื่องขอบเขตการใช้บังคับ เช่น "ประโยชน์ส่วนตน" "กิจการสื่อมวลชน"
3. ใส่เลขมาตราได้ไม่เกิน 2 มาตรา ห้ามไล่เลขเป็นช่วง
4. low ไม่เกิน 8 คำ high ไม่เกิน 6 คำ

ตัวอย่างที่เพิ่ม (จดเบอร์โทรเพื่อนลงสมุดส่วนตัว) ตั้งขึ้นใหม่ ไม่ได้ยกมาจากคำถามทดสอบ

## วิธีทดสอบ

รันใน container ที่เปิดอยู่ ไม่ restart server ทั้งสองฝั่งใช้โค้ดค้นและขยายกราฟของ branch เหมือนกัน ต่างกันเฉพาะ keywords: ฝั่งเก่าใช้ keywords จาก prompt เดิม (ที่บันทึกไว้จากรอบก่อน) ฝั่งใหม่เรียก LLM ด้วย prompt ใหม่หนึ่งครั้งต่อคำถาม (LLM: ชื่อโมเดลที่ส่งไป OpenRouter คือ `gpt-oss-120b` ตามค่า `LLM_MODEL` ใน `.env` แก้ไข 14 พ.ย. 2569: ฉบับแรกเขียนว่า `qwen/qwen3.5-35b-a3b` ซึ่งผิด ค่านั้นอยู่ในตัวแปร `OPENROUTER_MODEL` ที่ server ไม่ได้อ่าน)

| ชุด | จำนวน | บทบาท |
|---|---|---|
| Q1–Q8, N1–N7 | 15 | ตรวจว่าแย่ลงหรือไม่ |
| R1–R4 (คำตอบ สคส.) | 4 | เป็นชุดที่ทำให้เห็นปัญหาและใช้ออกแบบกติกา จึงไม่ใช่หลักฐานอิสระ |
| H1–H4 | 4 | ตั้งใหม่หลังเขียน prompt เสร็จ ไม่ได้ใช้ออกแบบ มาตราที่ควรได้กำหนดโดยผู้ทดสอบ |

H1 แอบบันทึกเสียงสนทนากับเพื่อนไว้ฟังเอง (ม.4), H2 ศาลเผยแพร่คำพิพากษาที่มีชื่อคู่ความ (ม.4), H3 นักเขียนเขียนชีวประวัติบุคคลมีชื่อเสียง (ม.4), H4 ร้านสะดวกซื้อติดกล้องวงจรปิดต้องแจ้งลูกค้าอย่างไร (ม.23 — ข้อควบคุม ไม่ควรได้รับผลจากกติกาข้อ 2)

## อ่านผล

- **ปัญหา ม.4 ดีขึ้นชัดเจน** จาก 0 เป็น 7 ใน 9 คำถาม รวมคำถาม H1–H3 ที่ไม่ได้ใช้ออกแบบ prompt (3 จาก 3) และ `sec_4` ขึ้นมาเป็น seed เองในหลายข้อ
- **แลกกับมาตราบทลงโทษที่หายไป** มาตราอื่นลดจาก 30 เป็น 27 จาก 35 ที่เสียเกือบทั้งหมดเป็นมาตราโทษ (ม.83 สี่ครั้ง, ม.84, ม.79, ม.78) สาเหตุที่น่าจะเป็นคือการจำกัด 8 + 6 คำ ทำให้คำเรื่องโทษถูกตัดออกเมื่อคำถามมีหลายประเด็น ยังไม่ได้ทดสอบแยกว่ากติกาข้อใดเป็นตัวการ
- **keywords สั้นลงมาก** เดิมเฉลี่ยราว 16 + 12 คำ (R3 เคยมี 52 คำ) เหลือ 8 + 6 และไม่มีการไล่เลขมาตราเป็นช่วงอีก แต่ LLM ยังเดาเลขมาตราผิดอยู่ เช่น "มาตรา 5 (ข้อยกเว้นกิจกรรมส่วนบุคคล)" ใน R3 และ "มาตรา 9", "มาตรา 13" ใน R1
- ข้อควบคุม H4 ไม่เปลี่ยน (ได้ ม.23 ทั้งสองฝั่ง)

## ข้อจำกัด

- สกัด keywords ด้วย prompt ใหม่ครั้งเดียวต่อคำถาม
- คำถาม ม.4 ทั้ง 9 ข้อ มี 6 ข้อที่เห็นมาก่อนเขียน prompt (Q6, Q7, R1–R4) หลักฐานอิสระมีเพียง H1–H3
- มาตราที่ควรได้ของ Q, N, H กำหนดโดยผู้ทดสอบ ของ R มาจากรายงานข่าวคำตอบ สคส.
- วัดเฉพาะสิ่งที่ server ส่งกลับ ไม่ได้วัดคุณภาพคำตอบของ agent
- ยังไม่ได้ build server ใหม่ container ที่รันอยู่ยังใช้โค้ด `main`
