# ผลทดสอบรอบ 6 — พยายามเอามาตราบทลงโทษกลับมาด้วย prompt (13 พ.ย. 2569)

ต่อจาก [รอบ 5](2026-11-13-keyword-prompt.md) ข้อมูลดิบอยู่ที่ [2026-11-13-keyword-prompt-penalty-results.json](2026-11-13-keyword-prompt-penalty-results.json)

**สรุป: ไม่สำเร็จ ทั้งสองแบบที่ลองไม่ดีกว่า prompt รอบ 5 จึงไม่ได้นำมาใช้ โค้ดใน branch ยังเป็น prompt รอบ 5**

## สิ่งที่ลอง

| แบบ | ต่างจาก prompt รอบ 5 อย่างไร |
|---|---|
| A | เพิ่มกติกา: ถ้าคำถามถามถึงโทษ ค่าปรับ ความรับผิด หรือค่าเสียหาย ต้องมีคำเรื่องนั้นใน low อย่างน้อย 1 คำ โดยใช้คำของตัวบท ("โทษปรับทางปกครอง", "โทษอาญา จำคุก", "ค่าสินไหมทดแทน") |
| B | เหมือน A และห้ามเดาเลขมาตรา ใส่ได้เฉพาะเลขที่คำถามระบุมาเอง ตัวอย่างใน prompt ก็เอาเลขมาตราออก |

ทดสอบกับ 23 คำถามเดิม วิธีเดียวกับรอบ 5 เรียก LLM หนึ่งครั้งต่อคำถามต่อแบบ

## ทำไม prompt แก้เรื่องนี้ไม่ได้

กติกาของแบบ A ได้ผลในระดับ keywords: Q1 และ Q8 มีคำว่า "โทษปรับทางปกครอง" และ "โทษอาญา" ครบ แต่มาตราโทษก็ยังไม่ถูกดึงมา ต้นเหตุอยู่ที่ขั้นค้นตัวบท ไม่ใช่ keywords:

- การค้นตัวบทใช้คำค้น **ก้อนเดียว** (low + high ต่อกัน) และรับ **5 มาตรา** คำถามที่มีสองประเด็น (หน้าที่ + โทษ) จึงต้องแย่งที่กัน
- ด้วย prompt เดิม ตัวบทที่ได้ของ Q1 คือ ม.79, 84, 83, 37, 82 คือ 4 ใน 5 เป็นมาตราโทษ มาตราโทษ "อยู่ครบ" เพราะกินที่ของมาตราหน้าที่ไป (ขาด ม.41, ม.40)
- ด้วย prompt ใหม่ ตัวบทของ Q1 คือ ม.37, 41, 40, 6, 4 คือได้มาตราหน้าที่ครบ แต่มาตราโทษหลุดทั้งหมด
- กราฟช่วยไม่ได้ เพราะไม่มีโหนดโทษและไม่มีเส้นจากมาตราหน้าที่ไป ม.82–84

การย้ายน้ำหนักด้วย prompt จึงเป็นการเลือกว่าจะเสียฝั่งไหน ไม่ได้ทำให้ได้ทั้งสองฝั่ง

## ข้อสังเกตเรื่องเกณฑ์

N6 ถามว่า "ต้องแจ้งภายในกี่ชั่วโมง และต้องแจ้งเจ้าของข้อมูลในกรณีใด" ไม่ได้ถามเรื่องโทษ แต่ผู้ทดสอบกำหนด ม.83 เป็นมาตราที่ควรได้ไว้ตั้งแต่รอบ 2 การที่ prompt ใหม่ไม่ดึง ม.83 ในข้อนี้จึงไม่ควรนับเป็นความเสียหาย ถ้าตัดออก มาตราอื่นของรอบ 5 คือ 27 จาก 34 เทียบกับ prompt เดิม 29 จาก 34

## ทางแก้ที่น่าจะตรงจุด (ยังไม่ได้ทำ)

1. ค้นตัวบทแยกสองรอบ (low หนึ่งรอบ high หนึ่งรอบ) เหมือนที่ค้น profile อยู่แล้ว หรือกันที่ 2 ใน 5 ไว้ให้คำค้นเรื่องโทษเมื่อ keywords มีคำเรื่องโทษ
2. เพิ่มโหนดโทษของ ม.82–84 และเส้นจากมาตราที่ถูกอ้างถึง (เช่น ม.37 → ม.83) ลงในกราฟ ให้การเดินกราฟพาไปถึงโทษได้เอง ซึ่งตรงกับแนวคิด GraphRAG ที่สอนมากกว่า

## ข้อจำกัด

- เรียก LLM ครั้งเดียวต่อคำถามต่อแบบ ความต่าง 1 มาตราระหว่างรอบ 5 กับแบบ A อยู่ในระดับที่อาจเกิดจากความแปรผันของ LLM
- มาตราที่ควรได้ของ Q, N, H กำหนดโดยผู้ทดสอบ
- วัดเฉพาะสิ่งที่ server ส่งกลับ ไม่ได้วัดคุณภาพคำตอบของ agent
