# ผลทดสอบรอบ 8 — ให้มาตราโทษที่อ้างถึงโหนดที่เดินถึงได้ลำดับแรก (13 พ.ย. 2569)

ต่อจาก [รอบ 7](2026-11-13-chunk-search.md) ข้อมูลดิบอยู่ที่ [2026-11-13-penalty-reference-results.json](2026-11-13-penalty-reference-results.json)

**สรุป: มาตราที่ควรได้ที่อยู่ใน context เพิ่มจาก 34 เป็น 40 (จาก 44) ไม่มีคำถามใดได้น้อยลง แก้โค้ดแล้ว**

## สิ่งที่แก้

กราฟมีเส้น `REFERENCES_SECTION` จากมาตราโทษไปยังมาตราหน้าที่อยู่แล้ว เช่น `sec_83 → sec_37`, `sec_84 → sec_26`, `sec_79 → sec_27`
แต่เส้นนี้อยู่ลำดับเดียวกับการอ้างข้ามมาตราทั่วไป และมักอยู่ที่ hop 2 จึงไม่ได้ที่ใน 15 บรรทัด

ใน `lightrag/retrieval.py`:

- `_is_penalty_section` — มาตราอยู่ในหมวด ๗ บทกำหนดโทษหรือไม่ ดูจากเส้น `CONTAINS_SECTION` จาก `ch7`, `ch7_p1`, `ch7_p2`
- `_candidate_priority` — มาตราโทษที่อ้าง "มายัง" โหนดที่เดินมาจาก ได้ลำดับ 0 เท่ากับ `PRESCRIBES_PENALTY`
- `_asks_about_penalty` — ยกลำดับเฉพาะเมื่อคำถามหรือ keywords มีคำเรื่องโทษ (โทษ, ปรับ, จำคุก, penalt, sanction, punish, imprison)

ไม่ได้แก้ข้อมูลกราฟ ไม่ต้อง build index ใหม่ การค้น profile และการค้นตัวบทไม่เปลี่ยน

## วิธีทดสอบ

ผลค้นตัวบทของก่อนแก้และหลังแก้เหมือนกันทุกข้อ ความต่างจึงมาจากการขยายกราฟอย่างเดียว และไม่มีความแปรผันจาก `top_k` แบบที่พบในรอบ 7

| ยกเมื่อถามเรื่องโทษ (ที่ใช้) | เหมือนข้างบน แต่เฉพาะเมื่อคำถามหรือ keywords มีคำเรื่องโทษ |

ทดสอบแบบที่ยกเฉพาะ hop 1 (มาตราโทษอ้าง seed โดยตรง) ด้วย ได้ 36 จาก 44 น้อยกว่าเพราะ seed มักเป็นโหนดนิยามหรือโหนดหน้าที่ มาตราหน้าที่อยู่ที่ hop 1 และมาตราโทษอยู่ที่ hop 2

## ข้อจำกัด

- เงื่อนไข "ยกเมื่อถามเรื่องโทษ" เลือกหลังจากเห็นผลของ 23 คำถามชุดนี้ และ 5 ใน 6 มาตราที่ได้เพิ่มอยู่ในชุดปรับจูน ยังไม่มีคำถามเรื่องโทษชุดที่กันไว้ต่างหาก
- ตัววัดนับเฉพาะมาตราในแนวคำตอบ โหนดที่ถูกเบียดออก (ข้อยกเว้น 11, Penalty 10, หน้าที่ 5 จาก 345 บรรทัด) ไม่กระทบตัวเลขนี้ แต่อาจกระทบคำตอบของ agent ซึ่งยังไม่ได้ทดสอบ
- มาตราโทษที่เข้ามามีทั้งที่ตรงและไม่ตรงกับผู้กระทำ เช่น `sec_37` พา ม.83 (ผู้ควบคุม) และ ม.86 (ผู้ประมวลผล) มาทั้งคู่ agent ต้องเลือกเอง
- คำว่า "ปรับ" ตรงกับคำอื่นได้ เช่น "ปรับปรุง" ผลคือยกลำดับมาตราโทษในคำถามที่ไม่ได้ถามเรื่องโทษ
- `get_penalty` ไม่ได้แก้ ยังคืนเฉพาะโหนด Penalty ตามข้อจำกัดใน README
