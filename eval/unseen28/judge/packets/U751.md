# การโอนข้อมูลลูกค้าไปเซิร์ฟเวอร์ต่างประเทศที่มาตรฐานไม่เพียงพอ — โทษปรับ

## บทบัญญัติ

**๑. หน้าที่ตามกฎหมาย — มาตรา ๒๘**
การส่งหรือโอนข้อมูลส่วนบุคคลไปต่างประเทศ ประเทศปลายทางหรือองค์การระหว่างประเทศที่รับข้อมูลต้องมี **มาตรฐานการคุ้มครองข้อมูลส่วนบุคคลที่เพียงพอ** ตามหลักเกณฑ์ที่คณะกรรมการประกาศ (มาตรา ๑๖ (๕)) เว้นแต่เข้าเหตุยกเว้น ๖ ประการ ได้แก่
1. เป็นการปฏิบัติตามกฎหมาย
2. ได้รับความยินยอมจากเจ้าของข้อมูล **โดยได้แจ้งให้ทราบถึงมาตรฐานที่ไม่เพียงพอของประเทศปลายทางแล้ว**
3. จำเป็นเพื่อปฏิบัติตามสัญญาที่เจ้าของข้อมูลเป็นคู่สัญญา หรือตามคำขอก่อนเข้าทำสัญญา
4. เป็นไปตามสัญญาระหว่างผู้ควบคุมข้อมูลกับบุคคลอื่นเพื่อประโยชน์ของเจ้าของข้อมูล
5. เพื่อป้องกัน/ระงับอันตรายต่อชีวิต ร่างกาย สุขภาพ เมื่อเจ้าของข้อมูลไม่อาจให้ความยินยอมได้
6. จำเป็นเพื่อดำเนินภารกิจเพื่อประโยชน์สาธารณะที่สำคัญ

และตาม **มาตรา ๒๙** มีช่องทางยกเว้นไม่ต้องปฏิบัติตาม ม.๒๘ ได้อีก เช่น กรณีโอนภายในเครือกิจการ/เครือธุรกิจเดียวกันตามนโยบายที่สำนักงานตรวจสอบรับรอง หรือกรณีจัดให้มีมาตรการคุ้มครองที่เหมาะสมบังคับตามสิทธิได้พร้อมมาตรการเยียวยาทางกฎหมาย

**๒. โทษปรับทางปกครอง (กรณีบริษัทเป็น "ผู้ควบคุมข้อมูลส่วนบุคคล")**
- **มาตรา ๘๓** — ฝ่าฝืน/ไม่ปฏิบัติตาม **มาตรา ๒๘** ต้องระวางโทษปรับทางปกครอง **ไม่เกิน ๓,๐๐๐,๐๐๐ บาท** (รวมถึงกรณีส่งหรือโอนข้อมูลโดยไม่เป็นไปตามมาตรา ๒๙ วรรคหนึ่งหรือวรรคสาม ด้วย)
- **มาตรา ๘๔** — หากการฝ่าฝืนมาตรา ๒๘ นั้น **เกี่ยวกับข้อมูลส่วนบุคคลตามมาตรา ๒๖ (ข้อมูลอ่อนไหว)** หรือส่ง/โอนข้อมูลตามมาตรา ๒๖ โดยไม่เป็นไปตามมาตรา ๒๙ วรรคหนึ่งหรือวรรคสาม ต้องระวางโทษปรับทางปกครอง **ไม่เกิน ๕,๐๐๐,๐๐๐ บาท**

**๓. โทษอาญา — มาตรา ๗๙**
ผู้ควบคุมข้อมูลส่วนบุคคลผู้ **ไม่ปฏิบัติตามมาตรา ๒๘ อันเกี่ยวกับข้อมูลส่วนบุคคลตามมาตรา ๒๖** (คือข้อมูลอ่อนไหว) โดยประการที่น่าจะทำให้ผู้อื่นเกิดความเสียหาย เสียชื่อเสียง ถูกดูหมิ่น ถูกเกลียดชัง หรือได้รับความอับอาย
- จำคุกไม่เกิน **๖ เดือน** หรือปรับไม่เกิน **๕๐๐,๐๐๐ บาท** หรือทั้งจำทั้งปรับ
- หากเพื่อ **แสวงหาประโยชน์ที่มิควรได้** สำหรับตนเองหรือผู้อื่น จำคุกไม่เกิน **๑ ปี** หรือปรับไม่เกิน **๑,๐๐๐,๐๐๐ บาท** หรือทั้งจำทั้งปรับ (ความผิดอันยอมความได้)

**๔. กรณีผู้ประมวลผลข้อมูล (processor) เป็นผู้โอน**
- **มาตรา ๘๖** — ส่ง/โอนข้อมูลโดยไม่เป็นไปตามมาตรา ๒๙ วรรคหนึ่งหรือวรรคสาม ปรับทางปกครองไม่เกิน **๓,๐๐๐,๐๐๐ บาท**
- **มาตรา ๘๗** — ส่ง/โอนข้อมูลตามมาตรา ๒๖ วรรคหนึ่งหรือวรรคสาม โดยไม่เป็นไปตามมาตรา ๒๙ วรรคหนึ่งหรือวรรคสาม ปรับทางปกครองไม่เกิน **๕,๐๐๐,๐๐๐ บาท**

## สรุปตัวเลขที่ตอบคำถาม
| ฐานความผิด | โทษ |
|---|---|
| ฝ่าฝืน ม.๒๘ (ข้อมูลทั่วไป) | ปรับทางปกครองไม่เกิน **๓ ล้านบาท** (ม.๘๓) |
| ฝ่าฝืน ม.๒๘ เกี่ยวกับข้อมูลอ่อนไหว ม.๒๖ | ปรับทางปกครองไม่เกิน **๕ ล้านบาท** (ม.๘๔) |
| ฝ่าฝืน ม.๒๘ + ทำให้เสียชื่อเสียง (ข้อมูลอ่อนไหว) | จำคุกไม่เกิน ๖ เดือน หรือปรับไม่เกิน ๕ แสน (ม.๗๙) |
| ฝ่าฝืน ม.๒๘ + แสวงหาประโยชน์มิชอบ | จำคุกไม่เกิน ๑ ปี หรือปรับไม่เกิน ๑ ล้าน (ม.๗๙) |

## คำแนะนำ
1. **ตรวจก่อนว่าเข้าข้อยกเว้นหรือไม่** — ถ้าบริษัทแจ้งความเสี่ยงเรื่องมาตรฐานปลายทางและได้ความยินยอมชัดแจ้ง (ม.๒๘(๒)) หรือมีมาตรการคุ้มครองที่เหมาะสมตาม ม.๒๙ วรรคสาม การโอนอาจทำให้ชอบและไม่ต้องรับโทษ
2. **แยกประเภทข้อมูล** — ถ้าข้อมูลลูกค้าที่โอนเป็นข้อมูลอ่อนไหวตาม ม.๒๖ (เชื้อชาติ ศาสนา สุขภาพ พันธุกรรม ชีวภาพ ฯลฯ) เพดานโทษจะขยับจาก ๓ ล้านเป็น ๕ ล้านบาท และอาจมีโทษอาญาตาม ม.๗๙ ด้วย
3. **แยกบทบาท** — ถ้าบริษัทเป็นผู้ควบคุมข้อมูล ให้ดู ม.๘๓/๘๔ และ ม.๗๙; ถ้าเป็นผู้ประมวลผล ให้ดู ม.๘๖/๘๗
4. **ปรับการโอนให้ถูกต้อง** — จัดทำมาตรการคุ้มครองที่เหมาะสม ใช้ข้อสัญญามาตรฐาน (SCC) หรือขอรับรองนโยบายจากสำนักงาน เพื่อใช้ช่องยกเว้นตาม ม.๒๙
5. โทษทางปกครองตาม ม.๘๓/๘๔/๘๖/๘๗ ยังอาจมี **โทษทางอาญา** ในกรณีของเจ้าหน้าที่/ผู้บริหารที่เกี่ยวข้องเพิ่มเติมได้ และมีโทษปรับรายวันกรณีไม่ปฏิบัติตามคำสั่งของคณะกรรมการผู้เชี่ยวชาญด้วย จึงควรปรึกษาฝ่ายกฎหมายก่อนดำเนินการโอน

(หมายเหตุ: คำตอบอ้างจากตัวบทที่ดึงผ่านระบบ PDPA — มาตรา ๒๖, ๒๘, ๒๙, ๗๙, ๘๓, ๘๔, ๘๖, ๘๗)
