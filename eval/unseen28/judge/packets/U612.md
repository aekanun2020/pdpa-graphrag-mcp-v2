# คำตอบ: การติดกล้องวงจรปิด (CCTV) ในร้านสะดวกซื้อ กับหน้าที่ตาม PDPA

## บทบัญญัติที่เกี่ยวข้อง

### 1. ร้านสะดวกซื้อมีสถานะเป็น "ผู้ควบคุมข้อมูลส่วนบุคคล"
ภาพใบหน้าลูกค้าที่กล้องบันทึกได้ถือเป็น **ข้อมูลส่วนบุคคล** และร้านเป็นผู้ตัดสินใจเกี่ยวกับการเก็บรวบรวม/ใช้/เปิดเผย จึงเป็น **ผู้ควบคุมข้อมูลส่วนบุคคล** ตามนิยามในมาตรา ๖ ซึ่งมีหน้าที่ตาม PDPA โดยตรง

### 2. หลักการพื้นฐาน: ต้องมีฐานทางกฎหมาย (มาตรา ๒๔)
มาตรา ๒๔ ห้ามเก็บรวบรวมข้อมูลส่วนบุคคลโดยไม่ได้รับความยินยอม **เว้นแต่** เข้าข้อยกเว้น
- **(๕) ประโยชน์โดยชอบด้วยกฎหมาย (Legitimate Interest)** — มูลฐานที่ร้านค้านิยมใช้กับ CCTV เพื่อความปลอดภัย ป้องกันทรัพย์สินและอาชญากรรม
- **(๒) ป้องกันหรือระงับอันตรายต่อชีวิต ร่างกาย หรือสุขภาพ**

> ถ้าใช้ฐาน (๕) ประโยชน์โดยชอบธรรมจะต้องไม่สำคัญน้อยกว่าสิทธิขั้นพื้นฐานของลูกค้า

### 3. ⭐ หน้าที่หลักที่ถาม: ต้องแจ้ง Privacy Notice (มาตรา ๒๓)
มาตรา ๒๓ กำหนดว่า **"ก่อนหรือในขณะเก็บรวบรวม"** ผู้ควบคุมข้อมูลส่วนบุคคลต้องแจ้งรายละเอียด ๖ ข้อ:

| ข้อ | สิ่งที่ต้องแจ้ง |
|---|---|
| (๑) | **วัตถุประสงค์** ของการเก็บรวบรวม เช่น เพื่อความปลอดภัย ป้องกันทรัพย์สิน |
| (๒) | กรณีต้องให้ข้อมูลเพื่อปฏิบัติตามกฎหมาย/สัญญา และผลกระทบหากไม่ให้ |
| (๓) | **ข้อมูลที่จะเก็บ** (ภาพ/เสียง) และ **ระยะเวลาจัดเก็บ** (เช่น เก็บ 30 วัน แล้วลบ) |
| (๔) | **ประเภทของบุคคล/หน่วยงาน** ที่ข้อมูลอาจถูกเปิดเผย (เช่น บริษัท รปภ., เจ้าหน้าที่ตำรวจ) |
| (๕) | **ข้อมูลผู้ควบคุมข้อมูล สถานที่ติดต่อ วิธีการติดต่อ** (และของ DPO ถ้ามี) |
| (๖) | **สิทธิของเจ้าของข้อมูล** ตาม ม.๑๙ วรรคห้า, ๓๐, ๓๑, ๓๒, ๓๓, ๓๔, ๓๖ และ ๗๓ |

ข้อยกเว้น: ไม่ต้องแจ้งถ้าลูกค้าทราบรายละเอียดนั้นอยู่แล้ว

### 4. หลักปฏิบัติอื่นที่เกี่ยวเนื่อง
- **มาตรา ๒๒ (Data Minimization)** — เก็บเท่าที่จำเป็นภายใต้วัตถุประสงค์อันชอบด้วยกฎหมาย
- **มาตรา ๒๑ (Purpose Limitation)** — ต้องใช้ข้อมูลตามวัตถุประสงค์ที่แจ้งไว้ ถ้าจะใช้วัตถุประสงค์ใหม่ต้องแจ้งและขอความยินยอมใหม่
- **มาตรา ๓๗ หน้าที่รักษาความมั่นคงปลอดภัย** — มีมาตรการป้องกันการเข้าถึง/เปิดเผยโดยมิชอบ, มีระบบลบ/ทำลายข้อมูลเมื่อพ้นระยะเวลา, และแจ้งเหตุละเมิดข้อมูลส่วนบุคคลต่อสำนักงานภายใน **72 ชั่วโมง**
- **มาตรา ๓๙** — บันทึกรายการ (ROPA) เช่น ข้อมูลที่เก็บ วัตถุประสงค์ ระยะเวลาจัดเก็บ ฯลฯ
- **สิทธิของลูกค้า** ที่ต้องแจ้งให้ทราบ ได้แก่ สิทธิขอเข้าถึง (ม.๓๐), สิทธิขอรับ/โอนข้อมูล (ม.๓๑), สิทธิคัดค้าน (ม.๓๒), สิทธิขอลบ (ม.๓๓), สิทธิขอระงับการใช้ (ม.๓๔), สิทธิขอแก้ไข (ม.๓๕-๓๖), และสิทธิถอนความยินยอม (ม.๑๙ วรรคห้า)

### 5. บทลงโทษหากไม่ปฏิบัติ (มาตรา ๘๒)
**มาตรา ๘๒** — ผู้ควบคุมข้อมูลส่วนบุคคลผู้ใดไม่ปฏิบัติตาม **มาตรา ๒๓** ... ต้องระวาง**โทษปรับทางปกครองไม่เกิน ๑,๐๐๐,๐๐๐ บาท**

## คำแนะนำเชิงปฏิบัติสำหรับร้านสะดวกซื้อ

1. **ติดป้ายแจ้ง (Privacy Notice) ที่ทางเข้าและ/หรือบริเวณที่มองเห็นได้ชัดเจน** ก่อนที่ลูกค้าจะเดินเข้าพื้นที่ที่กล้องบันทึกภาพ — ระบุวัตถุประสงค์, ระยะเวลาจัดเก็บ, ข้อมูลผู้ควบคุมและช่องทางติดต่อ, ผู้รับข้อมูล, และสิทธิของลูกค้า (ตามข้อ ๖ ของ ม.๒๓)
2. **กำหนดระยะเวลาจัดเก็บชัดเจน** เช่น ภาพ CCTV เก็บ 15–30 วัน แล้วลบอัตโนมัติ ตาม ม.๓๗(๓) และแจ้งในป้าย
3. **ใช้ฐานประโยชน์โดยชอบด้วยกฎหมาย (ม.๒๔(๕))** และจัดทำ **การประเมินความสมดุล (LIA)** ไว้เป็นหลักฐานว่าความปลอดภัยของร้านไม่น้อยไปกว่าสิทธิลูกค้า
4. **ควบคุมการเข้าถึง** ภาพให้เฉพาะผู้ที่จำเป็น ตั้งรหัสผ่าน/สิทธิ์ผู้ใช้ และมีสัญญากับบริษัทผู้ดูแลระบบกล้อง (ผู้ประมวลผลข้อมูล)
5. **จำกัดบริเวณกล้อง** ไม่ติดในห้องน้ำ/ห้องเปลี่ยนเสื้อผ้า เพราะจะเป็นการล่วงละเมิดเกินความจำเป็น
6. **จัดทำบันทึกรายการ (ROPA) ตาม ม.๓๙** และมี **ช่องทางรับคำขอใช้สิทธิ/ร้องเรียน** ของลูกค้า
7. **ถ้าเกิดเหตุข้อมูลรั่วไหล** ต้องแจ้งสำนักงานภายใน 72 ชั่วโมง และถ้ามีความเสี่ยงสูงต้องแจ้งลูกค้าด้วย (ม.๓๗(๔))

> หมายเหตุ: หากจะใช้ **ความยินยอม** เป็นฐานแทน (เช่น ในบางพื้นที่) การขอความยินยอมต้องเป็นไปตาม ม.๑๙ (ชัดแจ้ง เป็นหนังสือ/อิเล็กทรอนิกส์ แยกส่วน ถอนได้ง่าย) ซึ่งในทางปฏิบัติสำหรับ CCTV ทำได้ยากกว่า จึงนิยมใช้ฐานประโยชน์โดยชอบด้วยกฎหมายมากกว่า

*ข้อมูลทั้งหมดอ้างอิงจากตัวบทที่ดึงผ่านระบบ PDPA (ม.๖, ๑๙, ๒๑, ๒๒, ๒๓, ๒๔, ๓๐–๓๖, ๓๗, ๓๙, ๘๒)*
