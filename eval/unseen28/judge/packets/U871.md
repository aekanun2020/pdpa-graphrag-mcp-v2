## บทบัญญัติ

### ๑. สิทธิขอระงับการใช้ — มาตรา ๓๔

> เจ้าของข้อมูลส่วนบุคคลมีสิทธิขอให้ผู้ควบคุมข้อมูลส่วนบุคคลระงับการใช้ข้อมูลส่วนบุคคลได้ ในกรณีดังต่อไปนี้
> (๑) เมื่อผู้ควบคุมข้อมูลส่วนบุคคลอยู่ในระหว่างการตรวจสอบตามที่เจ้าของข้อมูลส่วนบุคคลร้องขอให้ดำเนินการตามมาตรา ๓๖
> (๒) เมื่อเป็นข้อมูลส่วนบุคคลที่ต้องลบหรือทำลายตามมาตรา ๓๓ (๔) แต่เจ้าของข้อมูลส่วนบุคคลขอให้ระงับการใช้แทน
> (๓) เมื่อข้อมูลส่วนบุคคลหมดความจำเป็นในการเก็บรักษาไว้ตามวัตถุประสงค์ในการเก็บรวบรวม แต่เจ้าของข้อมูลส่วนบุคคลมีความจำเป็นต้องขอให้เก็บรักษาไว้เพื่อใช้ในการก่อตั้งสิทธิเรียกร้องตามกฎหมาย ...
> (๔) เมื่อผู้ควบคุมข้อมูลส่วนบุคคลอยู่ในระหว่างการพิสูจน์ตามมาตรา ๓๒ (๑) หรือตรวจสอบตามมาตรา ๓๒ (๓) เพื่อปฏิเสธการคัดค้านของเจ้าของข้อมูลส่วนบุคคลตามมาตรา ๓๒ วรรคสาม
>
> กรณีผู้ควบคุมข้อมูลส่วนบุคคลไม่ดำเนินการตามวรรคหนึ่ง เจ้าของข้อมูลส่วนบุคคลมีสิทธิร้องเรียนต่อคณะกรรมการผู้เชี่ยวชาญเพื่อสั่งให้ผู้ควบคุมข้อมูลส่วนบุคคลดำเนินการได้
> คณะกรรมการอาจประกาศกำหนดหลักเกณฑ์ในการระงับการใช้ตามวรรคหนึ่งก็ได้

### ๒. สิทธิที่เกี่ยวเนื่อง — มาตรา ๓๕ และ มาตรา ๓๖ (สิทธิขอแก้ไขให้ถูกต้อง)

- **มาตรา ๓๕:** "ผู้ควบคุมข้อมูลส่วนบุคคลต้องดำเนินการให้ข้อมูลส่วนบุคคลนั้นถูกต้อง เป็นปัจจุบัน สมบูรณ์ และไม่ก่อให้เกิดความเข้าใจผิด"
- **มาตรา ๓๖:** "ในกรณีที่เจ้าของข้อมูลส่วนบุคคลร้องขอให้ผู้ควบคุมข้อมูลส่วนบุคคลดำเนินการตามมาตรา ๓๕ หากผู้ควบคุมข้อมูลส่วนบุคคลไม่ดำเนินการตามคำร้องขอ ผู้ควบคุมข้อมูลส่วนบุคคลต้องบันทึกคำร้องขอของเจ้าของข้อมูลส่วนบุคคลพร้อมด้วยเหตุผลไว้ในรายการตามมาตรา ๓๙ ให้นำความในมาตรา ๓๔ วรรคสอง มาใช้บังคับโดยอนุโลม"

→ การ "ตรวจสอบความถูกต้อง" จึงเป็นฐานของทั้งสิทธิขอแก้ไข (ม.๓๕/๓๖) และสิทธิขอระงับการใช้ระหว่างตรวจสอบ (ม.๓๔(๑))

### ๓. หน้าที่จัดทำบันทึกรายการ — มาตรา ๓๙

มาตรา ๓๙ วรรคหนึ่ง กำหนดให้ผู้ควบคุมข้อมูลส่วนบุคคลบันทึกรายการอย่างน้อย ได้แก่ ... **(๗) การปฏิเสธคำขอหรือการคัดค้านตามมาตรา ๓๐ วรรคสาม มาตรา ๓๑ วรรคสาม มาตรา ๓๒ วรรคสาม และมาตรา ๓๖ วรรคหนึ่ง** เพื่อให้เจ้าของข้อมูลและสำนักงานตรวจสอบได้

### ๔. ช่องทางบังคับเมื่อบริษัทไม่ดำเนินการ

- **มาตรา ๓๔ วรรคสอง:** เจ้าของข้อมูลมีสิทธิร้องเรียนต่อคณะกรรมการผู้เชี่ยวชาญเพื่อสั่งให้ผู้ควบคุมดำเนินการ
- **มาตรา ๗๓:** เจ้าของข้อมูลมีสิทธิร้องเรียนกรณีผู้ควบคุม/ผู้ประมวลผลฝ่าฝืนหรือไม่ปฏิบัติตาม พ.ร.บ. นี้

### ๕. เรื่องโทษ

ข้อนี้ต้องระวังการอ้าง — จากการตรวจสอบกราฟบทลงโทษ **ไม่พบบทกำหนดโทษที่เชื่อมโยงโดยตรงกับมาตรา ๓๔ และมาตรา ๓๖** (get_penalty ของทั้งสองมาตราให้ผลเป็น 0 รายการ) ต่างจากกรณีอื่น เช่น

- **มาตรา ๘๒** ปรับทางปกครองไม่เกิน ๑,๐๐๐,๐๐๐ บาท — ครอบคลุมการไม่ปฏิบัติตาม **มาตรา ๒๓ / มาตรา ๓๐ วรรคสี่ / มาตรา ๓๙ วรรคหนึ่ง / มาตรา ๔๑ วรรคหนึ่ง / มาตรา ๔๒** (ไม่รวม ม.๓๔, ม.๓๖)
- **มาตรา ๘๓** ปรับทางปกครองไม่เกิน ๓,๐๐๐,๐๐๐ บาท — ครอบคลุม **มาตรา ๒๑ / ๒๒ / ๒๔ / ๒๕ วรรคหนึ่ง / ๒๗ / ๒๘ / ๓๒ วรรคสอง / ๓๗** ฯลฯ (ไม่รวม ม.๓๔, ม.๓๖)

ดังนั้น อย่าไปอ้างว่าฝ่าฝืน ม.๓๔ แล้วปรับตาม ม.๘๒/๘๓ โดยตรง — ช่องทางคือการถูก "ร้องเรียนต่อคณะกรรมการผู้เชี่ยวชาญ" และคำสั่งของคณะกรรมการ (ซึ่ง ม.๙๐ ให้อำนาจคณะกรรมการผู้เชี่ยวชาญสั่งลงโทษปรับทางปกครองได้) ส่วนความเสี่ยงที่ชัดเจนกว่าคือการไม่ปฏิบัติตาม **ม.๓๙ วรรคหนึ่ง** (ไม่บันทึกรายการ) ซึ่งเข้าข่าย **ม.๘๒ ปรับไม่เกิน ๑ ล้านบาท**

## คำแนะนำในการปฏิบัติ

1. **รับคำขอเป็นลายลักษณ์อักษร** และยืนยันตัวตนเจ้าของข้อมูลก่อนดำเนินการ
2. **ประเมินว่าตกในกรณีใดของ ม.๓๔** — เคสนี้คือ ม.๓๔(๑) เพราะเป็นการตรวจสอบความถูกต้องตามคำร้องขอของเจ้าของข้อมูล (ม.๓๖) จึงต้อง**ระงับการใช้องค์กรระหว่างตรวจสอบ** (เช่น หยุดใช้เพื่อวัตถุประสงค์อื่นที่ไม่ใช่เพื่อการตรวจสอบความถูกต้อง)
3. **แยกข้อมูลออกจากกันชัดเจน** เพื่อป้องกันการใช้ปะปน (หลักการเดียวกับ ม.๓๒ วรรคสอง ซึ่งกำหนดให้ต้อง "ปฏิบัติโดยแยกส่วนออกจากข้อมูลอื่นอย่างชัดเจนในทันที")
4. **เร่งตรวจสอบความถูกต้องให้เสร็จโดยไม่ชักช้า** ตามหน้าที่ใน ม.๓๕ แล้วแจ้งผลให้เจ้าของข้อมูลทราบ — ถ้าไม่ดำเนินการตามคำร้องขอ ต้อง**บันทึกคำร้องขอพร้อมเหตุผลไว้ในรายการตาม ม.๓๙** (ม.๓๖)
5. **บันทึกทุกคำขอ/การปฏิเสธลงในรายการ (ROPA)** ตาม ม.๓๙(๗) เพราะเป็นหน้าที่ตรงและมีโทษตาม ม.๘๒
6. **อย่าเพิ่งลบข้อมูล** เพียงเพราะถูกขอระงับ — ม.๓๔(๒) ชี้ชัดว่าการขอระงับใช้แทนการลบตาม ม.๓๓(๔) เป็นคนละกรณี ต้องดูเจตนาของคำขอ
7. **ถ้าปฏิเสธคำขอ** ต้องมีเหตุผลที่ชอบด้วยกฎหมายและบันทึกไว้ พร้อมแจ้งสิทธิร้องเรียนต่อคณะกรรมการผู้เชี่ยวชาญ (ม.๓๔ วรรคสอง) และสิทธิร้องเรียนตาม ม.๗๓
8. **ข้อสังเกตเชิงปฏิบัติ:** ตัวบท ม.๓๔ ไม่ได้กำหนดกรอบเวลาในการดำเนินการไว้ชัดเจนเหมือน ม.๓๐ วรรคสี่ (๓๐ วัน) จึงควรกำหนด SLA ภายในของบริษัทให้สั้นและสมเหตุสมผล เพราะคณะกรรมการอาจออกประกาศกำหนดหลักเกณฑ์การระงับการใช้เพิ่มเติมตาม ม.๓๔ วรรคสาม
