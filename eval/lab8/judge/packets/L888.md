# ตอบสั้น

**ขึ้นอยู่กับว่าใครถ่าย เพื่ออะไร และเอาไปทำอะไรต่อ** — ตัวการ "ถ่ายรูป/ถ่ายคลิปที่มีคนอื่นติดมา" เข้าข่ายเป็น "การเก็บรวบรวมข้อมูลส่วนบุคคล" ตาม PDPA ถ้าภาพนั้นระบุตัวบุคคลได้ แต่ PDPA มีข้อยกเว้นที่สำคัญคือ **กิจกรรมส่วนตัว/ในครอบครัวเท่านั้น** (ม.4(1)) ถ้าเป็นการถ่ายเพื่อใช้ส่วนตัวล้วน ๆ ก็มักไม่เข้าข่ายบังคับ แต่ถ้าเอาไป **ใช้/เปิดเผย** เช่น โพสต์สาธารณะ ใช้เชิงพาณิชย์ หรือถ่ายในฐานะผู้ประกอบการ/หน่วยงาน กฎจะเริ่มจับ

## 1. บทบัญญัติที่เกี่ยวข้อง

### 1.1 ภาพ/คลิปเป็น "ข้อมูลส่วนบุคคล" หรือไม่
**มาตรา 6** นิยาม "ข้อมูลส่วนบุคคล" = ข้อมูลเกี่ยวกับบุคคลซึ่งทำให้สามารถระบุตัวบุคคลนั้นได้ ไม่ว่าทางตรงหรือทางอ้อม
→ ภาพหรือคลิปที่มีใบหน้า/ลักษณะที่ระบุตัวบุคคลได้ = ข้อมูลส่วนบุคคล

### 1.2 ข้อยกเว้นที่ทำให้ PDPA ไม่ใช้บังคับเลย (สำคัญที่สุดในกรณีนี้)
**มาตรา 4** PDPA ไม่ใช้บังคับแก่
- **(1) การเก็บรวบรวม ใช้ หรือเปิดเผยข้อมูลส่วนบุคคลของบุคคลที่ทำการเก็บรวบรวมเพื่อประโยชน์ส่วนตนหรือเพื่อกิจกรรมในครอบครัวของบุคคลนั้นเท่านั้น** ← ข้อยกเว้นหลักสำหรับ "ถ่ายเล่น/ถ่ายเก็บไว้ดูเองในครอบครัว"
- (3) ผู้ที่เก็บรวบรวมไว้เฉพาะเพื่อ **กิจการสื่อมวลชน งานศิลปกรรม หรืองานวรรณกรรม** อันเป็นไปตามจริยธรรมแห่งวิชาชีพ หรือเป็นประโยชน์สาธารณะเท่านั้น (เช่น ภาพข่าว)
- (2) (4) (5) (6) หน่วยงานความมั่นคง / รัฐสภา / ศาล / ข้อมูลเครดิต

**ข้อควรระวัง:** ข้อยกเว้น ม.4(1) ใช้ได้เฉพาะเมื่อ**เพื่อประโยชน์ส่วนตนหรือกิจกรรมในครอบครัว "เท่านั้น"** ถ้าเอาไปเผยแพร่ต่อสาธารณะในวงกว้าง ใช้หารายได้ หรือใช้ในฐานะผู้ประกอบการ ข้อยกเว้นนี้มักตีความไม่ครอบคลุม และวรรคสามของ ม.4 ยังกำหนดให้ผู้ควบคุมข้อมูลตาม (2)(3)(4)(5)(6) ต้องจัดให้มีการรักษาความมั่นคงปลอดภัยตามมาตรฐานด้วย

### 1.3 ถ้า PDPA ใช้บังคับ ต้องมี "ฐาน" ในการเก็บรวบรวม
**มาตรา 19** ผู้ควบคุมข้อมูลส่วนบุคคลจะเก็บรวบรวม ใช้ หรือเปิดเผยข้อมูลส่วนบุคคลไม่ได้ หากเจ้าของข้อมูลไม่ได้ให้ความยินยอมไว้ก่อนหรือในขณะนั้น เว้นแต่กฎหมายบัญญัติให้กระทำได้
**มาตรา 24** ห้ามเก็บรวบรวมโดยไม่ได้รับความยินยอม เว้นแต่
- (1) จดหมายเหตุ/วิจัย/สถิติ/ประโยชน์สาธารณะ
- (2) ป้องกันหรือระงับอันตรายต่อชีวิต ร่างกาย สุขภาพ
- (3) จำเป็นเพื่อปฏิบัติตามสัญญา
- (4) ภารกิจเพื่อประโยชน์สาธารณะ/การใช้อำนาจรัฐ
- **(5) จำเป็นเพื่อประโยชน์โดยชอบด้วยกฎหมาย (legitimate interest) ของผู้ควบคุมข้อมูลหรือบุคคลอื่น เว้นแต่ประโยชน์นั้นสำคัญน้อยกว่าสิทธิขั้นพื้นฐานในข้อมูลส่วนบุคคลของเจ้าของข้อมูล**
- (6) ปฏิบัติตามกฎหมาย

→ ฐานที่มักถูกอ้างในบริบทกล้อง/ภาพ คือ **ม.24(5) legitimate interest** (เช่น กล้องวงจรปิดเพื่อความปลอดภัย) ซึ่งต้องผ่านการชั่งน้ำหนักกับสิทธิของเจ้าของข้อมูล และเจ้าของข้อมูลยังมี **สิทธิคัดค้านตาม ม.32(1)** ได้

### 1.4 การ "ใช้" หรือ "เปิดเผย" (เช่น โพสต์ เผยแพร่ ส่งต่อ)
**มาตรา 27 วรรคหนึ่ง** ห้ามผู้ควบคุมข้อมูลส่วนบุคคลใช้หรือเปิดเผยข้อมูลส่วนบุคคลโดยไม่ได้รับความยินยอม เว้นแต่เป็นข้อมูลที่เก็บรวบรวมได้โดยได้รับยกเว้นตาม ม.24 หรือ ม.26
วรรคสอง — ผู้ที่ได้รับข้อมูลจากการเปิดเผยต่อ จะนำไปใช้/เปิดเผยเพื่อวัตถุประสงค์อื่นนอกเหนือจากที่แจ้งไว้ไม่ได้
วรรคสาม — ถ้าใช้/เปิดเผยโดยอาศัยข้อยกเว้น ต้องบันทึกไว้ในรายการตาม **ม.39**

### 1.5 ถ้าภาพนั้นเป็น "ข้อมูลอ่อนไหว"
**มาตรา 26** ห้ามเก็บรวบรวมข้อมูลอ่อนไหว (เชื้อชาติ เผ่าพันธุ์ ความคิดเห็นทางการเมือง ความเชื่อทางศาสนา พฤติกรรมทางเพศ ประวัติอาชญากรรม ข้อมูลสุขภาพ ความพิการ ข้อมูลสหภาพแรงงาน ข้อมูลพันธุกรรม **ข้อมูลชีวภาพ** ฯลฯ) **โดยไม่ได้รับความยินยอมโดยชัดแจ้ง** โดยมีข้อยกเว้นจำกัดเฉพาะ (1)–(5)
→ เช่น ถ่ายคลิปในโรงพยาบาล งานประท้วง หรือภาพที่เผยความเชื่อทางศาสนา อาจกลายเป็นข้อมูลอ่อนไหวที่ต้องใช้ consent โดยชัดแจ้ง และ ม.26 **ไม่มี** ข้อยกเว้น "ประโยชน์โดยชอบด้วยกฎหมาย" แบบ ม.24(5)

### 1.6 หน้าที่แจ้งและสิทธิของเจ้าของข้อมูล
- **ม.23** ต้องแจ้งรายละเอียดก่อนหรือในขณะเก็บรวบรวม (วัตถุประสงค์, ประเภทข้อมูล, ระยะเวลาเก็บ, สิทธิของเจ้าของข้อมูล ฯลฯ) เว้นแต่เจ้าของข้อมูลทราบอยู่แล้ว — เช่น ป้ายแจ้งว่ามีกล้องวงจรปิด
- **ม.32** สิทธิคัดค้านการเก็บรวบรวม ใช้ หรือเปิดเผย (รวมกรณีที่เก็บโดยอาศัยข้อยกเว้นตาม ม.24(4)/(5))
- **ม.33** สิทธิขอให้ลบ/ทำลาย/ทำให้ไม่สามารถระบุตัวบุคคลได้ ในกรณีที่ระบุไว้ เช่น ข้อมูลหมดความจำเป็น, ถอนความยินยอมแล้วและไม่มีอำนาจตามกฎหมายจะเก็บต่อ, คัดค้านตาม ม.32(1) แล้วผู้ควบคุมปฏิเสธไม่ได้, หรือถูกเก็บโดยไม่ชอบด้วยกฎหมาย

### 1.7 บทลงโทษ

**โทษอาญา — มาตรา 79**
- ฝ่าฝืน **ม.27 วรรคหนึ่งหรือวรรคสอง** (หรือไม่ปฏิบัติตาม ม.28 อันเกี่ยวกับข้อมูลตาม ม.26) **โดยประการที่น่าจะทำให้ผู้อื่นเกิดความเสียหาย เสียชื่อเสียง ถูกดูหมิ่น ถูกเกลียดชัง หรือได้รับความอับอาย** → **จำคุกไม่เกิน 6 เดือน หรือปรับไม่เกิน 500,000 บาท หรือทั้งจำทั้งปรับ**
- ถ้าทำ **เพื่อแสวงหาประโยชน์ที่มิควรได้โดยชอบด้วยกฎหมายสำหรับตนเองหรือผู้อื่น** → **จำคุกไม่เกิน 1 ปี หรือปรับไม่เกิน 1,000,000 บาท หรือทั้งจำทั้งปรับ**
- **ความผิดตามมาตรานี้เป็นความผิดอันยอมความได้**

**โทษปรับทางปกครอง**
- **มาตรา 83** ผู้ควบคุมข้อมูลส่วนบุคคลผู้ใดฝ่าฝืนหรือไม่ปฏิบัติตาม **ม.24** หรือ **ม.27 วรรคหนึ่งหรือวรรคสอง** (รวมถึงกรณีอื่นตามที่ระบุ) → **ปรับทางปกครองไม่เกิน 3,000,000 บาท**
- **มาตรา 84** ฝ่าฝืน **ม.26 วรรคหนึ่งหรือวรรคสาม** หรือฝ่าฝืน ม.27 วรรคหนึ่ง/วรรคสอง **อันเกี่ยวกับข้อมูลส่วนบุคคลตาม ม.26** → **ปรับทางปกครองไม่เกิน 5,000,000 บาท**

*หมายเหตุ:* เครื่องมือ get_penalty('sec_24') ให้ผล 0 (ไม่พบเส้นเชื่อมในกราฟ) แต่ตัวบท **ม.83** ที่อ่านมาจริงระบุ "มาตรา ๒๔" ไว้ชัดเจนในรายการที่ต้องระวางโทษปรับทางปกครองไม่เกินสามล้านบาท จึงอ้างอิงตามตัวบท

## 2. คำแนะนำเชิงปฏิบัติ (แยกจากตัวบท)

1. **ถ่ายเพื่อใช้ส่วนตัว/ในครอบครัวเท่านั้น** (เก็บไว้ดูเอง ไม่เผยแพร่) → โดยทั่วไปเข้าข้อยกเว้น **ม.4(1)** ไม่ต้องขอ consent ตาม PDPA
2. **ถ้าจะเผยแพร่ต่อสาธารณะ** (โพสต์โซเชียล เผยแพร่ในวงกว้าง) → หลุดจากข้อยกเว้น ม.4(1) อย่างน้อยควรขอความยินยอม หรือทำให้ใบหน้าไม่สามารถระบุตัวตนได้ (เบลอ/เบี่ยงมุม) และแจ้งวัตถุประสงค์ตาม **ม.23**
3. **ถ้าเป็นการใช้งานเชิงธุรกิจ/ในฐานะผู้ประกอบการ** (เช่น ร้านค้าถ่ายลูกค้าเพื่อการตลาด, กล้องวงจรปิด) → ถือเป็น "ผู้ควบคุมข้อมูลส่วนบุคคล" ต้องมีฐานตาม **ม.24** (มักใช้ ม.24(5) พร้อมชั่งน้ำหนักสิทธิ) หรือความยินยอมตาม **ม.19** + แจ้งตาม **ม.23** + จัดทำรายการตาม **ม.39** + มีมาตรการความมั่นคงปลอดภัยตาม **ม.37**
4. **ถ้าภาพเป็นข้อมูลอ่อนไหว** (สุขภาพ ความเชื่อ พฤติกรรมทางเพศ ฯลฯ) → ต้อง **ความยินยอมโดยชัดแจ้ง** ตาม **ม.26** และความรับผิดทางปกครองสูงถึง 5 ล้านบาท (ม.84) ไม่สามารถอ้าง ม.24(5) legitimate interest ได้
5. **ควรแจ้งให้เจ้าของข้อมูลใช้สิทธิ** ตาม ม.32 (คัดค้าน) และ ม.33 (ลบ) และปฏิบัติตามคำขอ
6. **ความเสี่ยงอาญาจะสูงขึ้น** ถ้าการใช้/เปิดเผยนั้นทำให้ผู้อื่นเสียชื่อเสียง/อับอาย (ม.79 วรรคหนึ่ง) หรือทำเพื่อแสวงหาประโยชน์ (ม.79 วรรคสอง) — และเป็นความผิดอันยอมความได้ จึงขึ้นกับว่าผู้เสียหายจะร้องทุกข์
7. **PDPA ไม่ใช่กฎหมายเดียวที่เกี่ยว** — การถ่ายภาพ/เผยแพร่ภาพบุคคลอาจมีประเด็นกฎหมายอื่น (เช่น ละเมิด หมิ่นประมาท หรือสิทธิในภาพ) ซึ่งต้องพิจารณาแยกจาก PDPA กรณีที่มีข้อเท็จจริงเฉพาะ (เช่น เผยแพร่ไปแล้วกี่คน มีการใช้หารายได้หรือไม่) แนะนำปรึกษาทนายความหรือสำนักงานคณะกรรมการคุ้มครองข้อมูลส่วนบุคคล (สคส.)

หากต้องการ เจาะกรณีเฉพาะ (เช่น กล้องวงจรปิด, การโพสต์ภาพในกลุ่มปิด, การถ่ายภาพในที่สาธารณะ) บอกข้อเท็จจริงมาได้ ผมจะค้นมาตราที่เกี่ยวข้องให้ละเอียดขึ้นครับ
